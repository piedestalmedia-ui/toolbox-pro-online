Privacy Policy

Last updated: October 6, 2026

This policy describes the static ToolBox Pro website published at piedestalmedia-ui.github.io/toolbox-pro-online. The site does not require an account.

Information processed by tools

Image files, text, and calculator values for local tools are processed in your browser. The site code does not upload those inputs to a ToolBox Pro server. If you copy or download a result, your browser handles that action.

Third-party services

  • YouTube thumbnail previews request public image URLs from YouTube’s image host. Embedded videos load from YouTube’s privacy-enhanced embed domain.
  • The QR Code Generator sends the entered text or URL to api.qrserver.com to produce a QR image. Do not enter confidential information into that tool.
  • Google Fonts may receive a request for the site’s typefaces when the page loads.

Those providers operate under their own policies. ToolBox Pro does not include analytics or advertising scripts in this release.

GitHub Pages hosting

The site is hosted by GitHub Pages. GitHub may process technical request data under its own privacy terms. For details, review GitHub’s current privacy statement.

Contact

For a privacy question, use the contact page or open a GitHub issue. Do not post private data in a public issue.
